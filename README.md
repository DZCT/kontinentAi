# ✦ kontinentAi · DZCT

ربات شخصی تلگرام با رابط فارسی، منوهای دکمه‌ای و اتصال مستقیم به API سرویس KontinentAI.

[مخزن GitHub](https://github.com/DZCT/kontinentAi) · [گزارش مشکل پروژه](https://github.com/DZCT/kontinentAi/issues) · [دانلود سورس](https://github.com/DZCT/kontinentAi/archive/refs/heads/main.zip)

این مخزن نسخهٔ مستقل برای **نصب اولیه روی سرور جدید** است. هیچ توکن، API key، گفتگو یا سابقهٔ مصرفی همراه آن نیست. برای اجرای آن حساب KontinentAI و ربات تلگرام خودتان را نیاز دارید.

## امکانات

- منوی اصلی، میانبرهای ثابت و انتخاب مدل صفحه‌بندی‌شده با نمایش قیمت و قابلیت‌ها.
- گفتگو با حافظهٔ SQLite، تحلیل عکس برای مدل‌های سازگار و دریافت PDF متنی و فایل کد.
- تنظیم شخصیت دستیار، طول خروجی، reasoning و JSON با دکمه.
- ثبت هزینهٔ گزارش‌شدهٔ API، گزارش مصرف روزانه و بودجهٔ قابل تنظیم.
- دسترسی به Chat Completions، Messages، Responses و شمارش توکن در حالت پیشرفته.
- خروجی گفتگو، تأیید قبل از پاک کردن حافظه و محدودیت دسترسی به یک مالک در چت خصوصی.
- اجرا با systemd و long polling؛ بدون نیاز به دامنه، وب‌سرور یا پورت ورودی.

ظاهر دکمه‌ها را تم و نسخهٔ تلگرام تعیین می‌کند. اجرای خودکار tool calls، تبدیل صدا و تولید تصویر در این پروژه ارائه نشده است؛ قابلیت‌های API نیز به پشتیبانی سرویس و مدل بستگی دارند. حضور مدل در فهرست، در دسترس بودن لحظه‌ای آن را تضمین نمی‌کند.

## پیش‌نیازها

- VPS با Ubuntu 22.04 یا جدیدتر، Python 3.10+ و دسترسی sudo.
- دسترسی اینترنت به Telegram، KontinentAI و مخازن نصب Python/Ubuntu.
- توکن ربات از [@BotFather](https://t.me/BotFather).
- شناسهٔ **عددی حساب خودتان**، مثلاً از [@userinfobot](https://t.me/userinfobot).
- کلید API حساب خودتان از [KontinentAI](https://kontinentai.com).

فقط یک نمونه با هر توکن ربات اجرا کنید. برای polling نباید webhook فعال داشته باشید. نصب‌کننده webhook قبلی را حذف نمی‌کند.

## نصب با یک دستور Bash

برای **نصب اولیه روی سرور جدید**، در Termius یا ترمینال SSH این دستور را کامل کپی کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DZCT/kontinentAi/main/install.sh)
```

این دستور بعد از انتشار فایل‌های همین پروژه در شاخهٔ `main` مخزن **عمومی** `DZCT/kontinentAi` کار می‌کند. اگر مخزن هنوز ساخته نشده یا خصوصی باشد، دانلود عمومی خطای 404 می‌دهد. وجود `curl` روی سرور لازم است؛ اگر پیام `curl: command not found` دیدید، ابتدا `sudo apt update && sudo apt install -y curl` را اجرا کنید و سپس دستور بالا را بزنید.

### مراحل نصب برای کاربر مبتدی

۱. در Termius به VPS وصل شوید و دستور بالا را اجرا کنید. اگر sudo رمز خواست، رمز سرور خودتان را وارد کنید.
۲. صبر کنید ابزارها و فایل‌های پروژه دانلود و نصب شوند.
۳. وقتی `1/3 Telegram bot token` آمد، توکن گرفته‌شده از BotFather را Paste کنید و Enter بزنید.
۴. در `2/3 Your numeric Telegram user ID` شناسهٔ عددی حساب خودتان را بنویسید و Enter بزنید.
۵. در `3/3 Kontinent API key` کلید API حساب خودتان را Paste کنید و Enter بزنید.
۶. هنگام وارد کردن توکن و کلید هیچ حرفی روی صفحه نمایش داده نمی‌شود؛ طبیعی است. اگر قالب اطلاعات اشتباه باشد، برنامه دوباره آن‌ها را می‌پرسد.
۷. پس از پیام `INSTALL OK` این دستور را برای وضعیت اجرا کنید:

```bash
sudo systemctl status kontinent-bot --no-pager
```

۸. اگر `active (running)` بود، وارد ربات خود در تلگرام شوید و `/start` بفرستید. مدل را از منو انتخاب و سؤال کوتاهی بفرستید.

نصب‌کننده فایل‌ها را در `/opt/kontinent-bot` قرار می‌دهد، کاربر محدود `kontinent` می‌سازد، تنظیمات را خصوصی ذخیره و اجرای خودکار systemd را فعال می‌کند. اگر نصب قبلی پیدا کند، قبل از تغییر آن متوقف می‌شود. این دستور کد همین مخزن را دریافت و با دسترسی نصب اجرا می‌کند؛ اطلاعات خود را فقط در ترمینال سرورتان وارد کنید.

### روش جایگزین برای بررسی اسکریپت قبل از اجرا

```bash
curl -fsSL https://raw.githubusercontent.com/DZCT/kontinentAi/main/install.sh -o install.sh
less install.sh
bash install.sh
```

## نصب از ZIP با گوشی و Termius

اگر ربات قبلی شما در `/opt/kontinent-bot` فعال است، **این نصب‌کننده را روی همان سرور اجرا نکنید**؛ این بسته برای فردی است که برای اولین بار نصب می‌کند. نصب‌کننده در صورت وجود نصب قبلی متوقف می‌شود.

۱. فایل `kontinentAi.zip` را دانلود کنید.
۲. در Termius به VPS جدید وصل شوید. در بخش SFTP وارد `/tmp` شوید و ZIP را Upload کنید.
۳. در ترمینال دستورها را یکی‌یکی اجرا کنید:

```bash
sudo apt update
sudo apt install -y python3 unzip
sudo unzip -n /tmp/kontinentAi.zip -d /tmp
cd /tmp/kontinentAi
sudo python3 install.py
```

برنامه ابزارها را نصب می‌کند و سپس سه مقدار می‌پرسد:

```text
1/3 Telegram bot token:
2/3 Your numeric Telegram user ID:
3/3 Kontinent API key:
```

در هر مرحله مقدار خودتان را Paste کنید و Enter بزنید. **هنگام ورود توکن و API key چیزی روی صفحه نشان داده نمی‌شود؛ طبیعی است.** این اطلاعات به صورت محلی در `/opt/kontinent-bot/.env` ذخیره می‌شوند.

در پایان `INSTALL OK` را می‌بینید. وضعیت سرویس را بررسی کنید:

```bash
sudo systemctl status kontinent-bot --no-pager
```

اگر `active (running)` بود، در تلگرام `/start` بفرستید. از منوی مدل‌ها یک مدل انتخاب و سپس یک سؤال بفرستید. باز کردن منو هزینهٔ تولید پاسخ ندارد؛ سؤال هوش مصنوعی می‌تواند از اعتبارتان مصرف کند.

اگر نصب نیمه‌کاره ماند، خروجی خطا را نگه دارید. برای تکرار نصب، پوشهٔ نصب قبلی را کورکورانه پاک نکنید؛ ممکن است تنظیمات یا گفتگو در آن باشد.

## اجرا از سورس، بدون نصب‌کننده

این روش برای توسعه یا آزمایش است و systemd نصب نمی‌کند:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env
.venv/bin/python bot.py
```

مقادیر نمونه را در `.env` با اطلاعات خودتان عوض کنید. `TELEGRAM_OWNER_ID` شناسهٔ کاربر است، نه ربات، نام کاربری یا شمارهٔ موبایل. فایل `.env.example` را با اطلاعات واقعی پر نکنید؛ این فایل برای انتشار عمومی است.

## تنظیمات

| متغیر | کاربرد | پیش‌فرض نمونه |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن BotFather | نیاز به مقدار واقعی |
| `TELEGRAM_OWNER_ID` | شناسهٔ عددی مالک | نیاز به مقدار واقعی |
| `KONTINENT_API_KEY` | کلید سرویس | نیاز به مقدار واقعی |
| `DEFAULT_MODEL` | مدل اولیه | `deepseek-v4.1-flash` |
| `DAILY_BUDGET_USD` | سقف بررسی‌شدهٔ روزانه بر مبنای UTC | `1` |
| `TOTAL_BUDGET_USD` | سقف بررسی‌شدهٔ کل همین نصب | `25` |
| `DATABASE_PATH` | محل حافظه و گزارش مصرف | `data/bot.sqlite3` |

اعتبار ۲۵ دلار همراه پروژه نیست؛ این عدد فقط تنظیم پیش‌فرض بودجه است. مصرف سایت، Playground و برنامه‌های دیگر در گزارش ربات نیست. این محدودیت **سقف سخت دلاری نیست**؛ قبل از درخواست بررسی می‌شود و آخرین درخواست ممکن است از آن عبور کند. `/tokens` فقط خروجی را محدود می‌کند؛ ورودی و استدلال نیز می‌توانند هزینه داشته باشند.

تنظیمات سرویس را با این دستور ویرایش کنید و سپس restart کنید:

```bash
sudo nano /opt/kontinent-bot/.env
sudo systemctl restart kontinent-bot
```

## استفاده

| دستور | کاربرد |
|---|---|
| `/start` یا `/menu` | منوی اصلی |
| `/models` | فهرست و انتخاب مدل |
| `/new` | تأیید و شروع گفتگوی تازه |
| `/settings` | تنظیمات دکمه‌ای |
| `/stats` | مصرف ثبت‌شده، نه موجودی حساب |
| `/export` | دریافت گفتگو |
| `/help` | راهنمای دستورهای بیشتر |
| `/cancel` | لغو حالت پیشرفته یا ورود شخصیت |

- عکس را تکی و همراه کپشن سؤال بفرستید؛ مدل باید تصویر بخواند.
- فایل‌ها حداکثر ۸ مگابایت و متن قابل استخراج حداکثر ۱۰۰ هزار نویسه؛ PDF تا ۱۰۰ صفحه است. PDF اسکن‌شده OCR خودکار ندارد.
- حافظهٔ فعال حداکثر ۱۰ نوبت آخر گفتگو است. `/new` آن را پاک می‌کند، ولی حذف امن از دیسک و backup را تضمین نمی‌کند.
- فایل‌های پوشهٔ `examples` برای حالت پیشرفته‌اند: ابتدا `/raw chat`، `/raw messages`، `/raw responses` یا `/raw count` را بزنید، سپس JSON مربوط را ارسال کنید. شناسهٔ مدل را در صورت نیاز به مدل موجود در کاتالوگ تغییر دهید.
- حالت پیشرفته مستقل از شخصیت و حافظهٔ معمولی است؛ تمام بدنهٔ درخواست را خودتان می‌نویسید. پاسخ کامل JSON تحویل می‌شود؛ ابزارها خودکار اجرا نمی‌شوند. Streaming در رابط ارائه نشده است.

## توقف و نگهداری

```bash
# توقف
sudo systemctl stop kontinent-bot
# جلوگیری از روشن شدن خودکار بعد از reboot
sudo systemctl disable kontinent-bot
# فعال‌سازی و روشن کردن دوباره
sudo systemctl enable --now kontinent-bot
# گزارش خطا
sudo journalctl -u kontinent-bot -n 30 --no-pager
```

قبل از backup سرویس را متوقف کنید و پوشهٔ `data` و فایل `.env` را در محل خصوصی نگه دارید. گفتگو و عکس‌ها محلی و بدون رمزگذاری در SQLite ذخیره و برای پاسخ به API فرستاده می‌شوند.

### هزینهٔ نامشخص

در قطع ارتباط یا خاموشی وسط درخواست، ربات درخواست را خودکار تکرار نمی‌کند و ارسال پولی را قفل می‌کند. ابتدا هزینه را در داشبورد بررسی کنید. فقط بعد از بررسی، مبلغ واقعی را ثبت و قفل را رفع کنید؛ `0.01` مثال است و باید عوض شود:

```bash
sudo systemctl stop kontinent-bot
cd /opt/kontinent-bot
sudo -u kontinent .venv/bin/python reconcile.py --cost-usd 0.01
sudo systemctl start kontinent-bot
```

اگر قطعاً هزینه صفر بوده، `--cost-usd 0` استفاده کنید. موجودی واقعی از داشبورد سرویس بررسی می‌شود. خطای Provider که صریحاً «Nothing was charged» بگوید قفل تازه ایجاد نمی‌کند. خطای 502 عموماً به مسیر ارائهٔ مدل مربوط است؛ 401 به کلید و 402 به اعتبار. خطای 409 تلگرام معمولاً به اجرای همزمان چند نمونه مربوط است.
